# Project policy

N1 and M1 are available under the [Apache License 2.0](LICENSE). You can use,
modify, fork and redistribute the source under its terms.

The maintainers develop this repository. External contributions and pull
requests are closed. Bug reports are welcome through GitHub Issues.

Include the affected component, the binary version, your pool layout and the
shortest steps that reproduce the problem. Remove credentials, personal paths
and private data from any logs you share. Report vulnerabilities privately as
described in [SECURITY.md](SECURITY.md).
