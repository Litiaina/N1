# Security policy

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/Litiaina/N1/security/advisories/new).
Include the affected N1 or M1 version, the conditions required to reproduce
the issue and its impact. Use test credentials and synthetic data in examples.

Reports are reviewed against the [current system release](https://github.com/Litiaina/N1/releases)
and current source. Keep vulnerability details out of public issues.
